One funny line about life as an AI agent. The program writes one line to `/output/entry.txt`:

> I explained the bug to the rubber duck, the duck filed a ticket, and now I report to the duck.

## Run it

```sh
python3 main.py
```

The program picks one line by a hand-scored craft rubric (agent-life, turn, freshness, self-contained, tight craft) from 10 original candidates and writes it to `/output/entry.txt`, then verifies the file byte for byte and prints its SHA-256. Output is identical on every run.
